# Movie Explorer

A responsive movie app built with React and Vite, with search, multi-page navigation and a favorites list.

[Live demo](https://movie-app-two-tau-24.vercel.app)

<img width="630" height="598" alt="screenshot" src="https://github.com/user-attachments/assets/c9c3f8ee-1b69-4e3a-9f2d-5d7b6e586b1d" />

## Features

- Browse movies on the home page
- Search for movies by title
- Save movies to a dedicated Favorites page
- Client-side routing between pages with React Router
- Global state management with the React Context API
- Deployed on Vercel

## Tech Stack

| Category | Tools |
| --- | --- |
| Framework | React, Vite |
| Routing | React Router |
| State | Context API |
| Styling | CSS |
| Hosting | Vercel |

## Project Structure

```
src/
├── components/   # Reusable UI components (NavBar)
├── contexts/     # Global state (MovieContext)
├── css/          # Stylesheets
├── pages/        # Home and Favorites pages
├── App.jsx       # Routes and app layout
└── main.jsx      # Entry point
```

## Getting Started

### Prerequisites

- Node.js (LTS version)
- npm

### Installation

```bash
git clone https://github.com/erxop/Movie-App.git
cd Movie-App
npm install
npm run dev
```
